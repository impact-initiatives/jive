## Orchestrator Errors
These errors can fall into two main categories. Any issues under this category should be resolved before addressing other validation errors.

### Admin Errors
These are errors with the underlying validation process and could be issues related to:
- Underying code
- Dataset schemas
- Loading excel files

If an admin error is encountered it should be reported.

### Errors
These are errors related to the specific dataset and could be related to:
- Structural issues with the excel file. I.e - missing sheets, incorrectly named sheets/columns.
